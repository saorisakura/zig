   ```cmake
   add_custom_target(stage3 ALL
   ```

   这段代码定义了一个名为 `stage3` 的自定义构建目标，并指定它依赖于 `${PROJECT_BINARY_DIR}/stage3/bin/zig` 文件。这意味着在构建 `stage3` 目标时，会确保生成 `zig` 可执行文件。

2. **设置工作目录**：
   ```cmake
   set(ZIG2_WORKING_DIR "${PROJECT_SOURCE_DIR}")
   ```

3. **定义自定义构建命令**：
   ```cmake
   add_custom_command(
     OUTPUT "${PROJECT_BINARY_DIR}/stage3/bin/zig"

   ```

在编译 Zig 源码时，如果遇到 `unable to find llvm-config` 错误，通常是因为系统中没有安装 LLVM，或者 LLVM 的路径没有正确配置。以下是解决该问题的步骤：

### 安装 LLVM

1. **在 Ubuntu 上安装 LLVM**：
   ```sh
   sudo apt-get update
   sudo apt-get install llvm-dev
   ```

2. **在其他 Linux 发行版上安装 LLVM**：
   根据你的 Linux 发行版，使用相应的包管理器安装 LLVM。例如，在 Fedora 上：
   ```sh
   sudo dnf install llvm-devel
   ```

### 配置 LLVM 路径

如果 LLVM 已经安装，但 `llvm-config` 仍然无法找到，可能需要手动指定 `llvm-config` 的路径。

1. **查找 `llvm-config` 的路径**：
   ```sh
   which llvm-config
   ```
   这将输出 `llvm-config` 的路径，例如 `/usr/bin/llvm-config`。

2. **设置 `LLVM_CONFIG` 环境变量**：
   在终端中运行以下命令，将 `llvm-config` 的路径添加到环境变量中：
   ```sh
   export LLVM_CONFIG=/usr/bin/llvm-config
   ```

3. **在 CMake 配置中指定 `LLVM_CONFIG` 路径**：
   在运行 

cmake

 命令时，添加 `-DLLVM_CONFIG` 选项：
   ```sh
   cmake -B build -DLLVM_CONFIG=/usr/bin/llvm-config
   ```

### 示例步骤

1. **安装 LLVM**：
   ```sh
   sudo apt-get update
   sudo apt-get install llvm-dev
   ```

2. **查找 `llvm-config` 路径**：
   ```sh
   which llvm-config
   ```

3. **配置 CMake**：
   ```sh
   cmake -B build -DLLVM_CONFIG=/usr/bin/llvm-config
   ```

4. **编译项目**：
   ```sh
   cmake --build build --target stage3
   ```

5. **安装项目**：
   ```sh
   cmake --install build
   ```

通过这些步骤，你应该能够解决 `unable to find llvm-config` 错误，并成功编译和安装 Zig。
